# amrs-first-project # Open-Source Marketing Framework for Small Businesses

Welcome to the open-source repository for my marketing agency! This project is dedicated to providing free, high-converting marketing frameworks, ad templates, and automation scripts for small businesses and local companies looking to scale.

## 🚀 Services & Frameworks Included
* **Local SEO Checklist:** A step-by-step guide to ranking a local business on Google Maps.
* **Cold Outreach Scripts:** High-converting email and LinkedIn templates used to secure agency clients.
* **AI Prompt Library:** Custom prompts for ChatGPT/Claude to generate a month's worth of social media content in minutes.

## 🛠️ How to Use This Repository
Feel free to fork this repository, download the templates, and adapt them to your own marketing campaigns.
